# 示例查询协议

这里是新建演示仓库的约定，不代表现有辞书项目已采用这些字段。

```json
{
  "filters": {"syllable_count": 2, "pos": "verb", "sense_count": 1},
  "semantic_query": ""
}
```

- syllable_count：从用户明确表达的查询条件提取；不是通过汉字数估算词条音节数。
- pos：本演示使用 verb / noun；真实数据请使用其既有词性映射。
- sense_count：本演示将“单义”解析为 1；真实统计的义项口径仍需独立确定。
- filters：未提及的条件不填。空查询为 {}。
- semantic_query：本演示识别整个纯结构查询后置空；不识别时原样保留输入。

入口先判断结构过滤条件，必要时再做语义检索。索引中的缺失音节、缺失词性不可被静默当成不符合条件；真实系统需要报告缺失覆盖率。
