# 项目说明

本仓库是针对汉语辞书研究工作设计的本地协作启动包，不含你的真实数据或已有项目改动。

目标：用任务文件连接 Chat 的讨论、本地 Work 的资料整理和 Codex CLI 的执行。

## 长期保留的内容

| 内容 | 位置 | 更新方式 |
|---|---|---|
| 执行规则 | AGENTS.md | 用户或负责维护的人修改 |
| 研究目标与边界 | PROJECT.md | 研究方向变化时修改 |
| 数据结构与语义口径 | docs/data-schema.md、schemas/ | 明确决定后更新 |
| 已决定的设计 | docs/decisions/ | 每个决定单独存档 |
| 原始与派生数据 | data/raw/、data/processed/ | 分开保存并关联版本 |
| 程序和测试 | src/、tests/ | 通过任务分支修改 |

## 本示例边界

parse_query(text) 只演示自然语言中的结构条件解析。没有连接向量库、数据库、辞书或大模型 API。

真实任务中的“现代汉语词典有多少双音节动词”需要先确定辞书版次、词条/义项计数单位、兼类词计算方法、读音标准，再写数据库查询和验收样例。

自动化任务最多初次执行加一次修复；通过检查后停在待审阅状态。用户接纳后，调度器将候选提交快进合入本地主分支。
